# Holistic Semantic SEO Methodology: Semantic SEO Standard

SEO Skills AI is founded on the **Holistic Semantic SEO Framework**, prioritizing semantic source context, entity-attribute-value modeling, and mathematical link graph equity.

---

## 1. Entity-Attribute-Value (EAV) Modeling
Search engines rank entities, not strings. Before drafting content, our agents define:
- **Central Entity:** The primary topical subject.
- **Primary Attributes:** Essential characteristics and properties.
- **Contextual Values:** Specific data points and empirical evidence.

---

## 2. Centerpiece Viewport Annotation
The primary interactive or functional element must render within the top **350px viewport** (<600px mobile) to prevent centerpiece demotion penalties.

---

## 3. Directional Internal Link Conduits
Link equity flows systematically upwards and horizontally:
- **Outer Cluster Nodes $\rightarrow$ Category Silo Hub $\rightarrow$ Core Flagship Pillar.**
- Strict enforcement of **3x Anchor Diversity Rule**: Exact-match anchor text must never exceed 3 sitewide occurrences.
