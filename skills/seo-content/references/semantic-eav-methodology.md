# Holistic Semantic SEO & EAV Methodology Reference

Detailed framework for Entity-Attribute-Value (EAV) modeling, Visual Semantics, and Directional PageRank Conduits.

---

## 🏛️ 1. Entity-Attribute-Value (EAV) Modeling

To build true topical authority, every article must construct an explicit EAV network:
- **Central Entity ($E_0$):** The primary noun/concept defining the search topic (e.g. *Astro 5.0*).
- **Secondary Entities ($E_1 \dots E_n$):** Related core subjects (e.g. *Content Collections, Server Islands, View Transitions*).
- **Attributes ($A$):** Measurable properties (e.g. *Zero-JS baseline, CWV INP score, render latency*).
- **Contextual Values ($V$):** Concrete measurements (e.g. *<200ms, 0 client bytes, $0.009 cost*).

---

## 🔗 2. Directional Link Conduits & 3x Anchor Diversity Rule

1. **Link Directionality:**
   - Outer child nodes pass link equity systematically upwards into their **Category Silo Hub**, which concentrates PageRank and feeds the **Core Flagship Pillar**.
2. **Anchor Text Governance (3x Anchor Diversity Rule):**
   - No exact-match target keyword anchor text can appear more than **3 times across the entire website**.
   - Use semantic synonyms, descriptive phrases, and partial-match variations to avoid algorithmic over-optimization penalties.
