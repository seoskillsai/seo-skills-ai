# Generative Engine Optimization (GEO) Standard

Aligned with **Google's AI Optimization Guide** and LLM retrieval mechanics.

---

## 🔍 Core GEO Optimization Vectors

1. **Passage Citability Scoring:**
   - LLMs extract self-contained answer passages (optimal 130–170 words).
   - Each H2/H3 section must open with an authoritative summary paragraph directly answering the subsection's query.

2. **Entity Grounding & Triples:**
   - Link entities explicitly to authoritative sources (`sameAs` schema links to Wikipedia, Wikidata, GitHub).

3. **Multi-Source Brand Consensus:**
   - Maintain consistent NAP and entity facts across web sources (Reddit, YouTube, LinkedIn, GitHub).

4. **Primary-Source Evidence:**
   - Include unique empirical data, original benchmarks, and reproducible metrics to serve as citation bait for AI synthesizers.
