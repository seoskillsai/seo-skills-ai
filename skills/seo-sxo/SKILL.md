# Search Experience Optimization (SXO) & Retention Mastery

This skill optimizes the user's post-click search journey to eliminate bounce triggers, maximize dwell time, and fulfill search intent instantly.

---

## 🎯 The 4 Core SXO Principles

1. **Centerpiece Fold Annotation:**
   - The primary interactive element (calculator, quiz question, code generator, or direct answer) must render within the **top 350px viewport** (<600px on mobile).
   - Prevents "centerpiece demotion" penalties in Google ranking algorithms.

2. **Click-Input-Click Interactive Loops:**
   - Incorporate interactive elements (e.g. ROI savings slider, terminal command copier, live schema tester) to keep users actively engaged in the primary viewport.

3. **Session Continuation Pathways (Zero Dead Ends):**
   Every page must provide at least 3 distinct pathways to continue the session:
   - **Next-in-Cluster:** Next article in the active topic silo.
   - **Interactive Tool Escalation:** Open an interactive tool related to the article.
   - **Macro Silo Hub:** Link upward to the category pillar.

4. **WCAG 2.1 AA Accessibility Standards:**
   - Minimum 4.5:1 text contrast ratio.
   - Clear visual keyboard focus rings (`:focus-visible`).
   - Semantic ARIA landmarks (`<main>`, `<nav>`, `<aside>`).
