# 10-Principle Falsifiable Diagnostic Reasoning Framework

Every recommendation produced by SEO Skills AI must strictly adhere to this 10-principle diagnostic methodology:

---

## 🏛️ The 10 Core Principles

1. **First-Principle Observation:** Never report an assertion without the exact underlying DOM node, HTTP header, or field metric that proves it.
2. **Deterministic Falsifiability:** Every action item must answer: *"How would we definitively prove this recommendation failed?"*
3. **Leading Indicator Definition:** Define the immediate 14-day metric (e.g. crawl frequency, impression lift) before revenue/rankings respond.
4. **Dependency Relationship Mapping:** Clearly specify prerequisite fixes (e.g. resolve 500 errors before canonicalizing).
5. **Entity-Attribute-Value (EAV) Modeling:** Build topical authority by modeling entities and attributes, not keyword stuffing.
6. **Centerpiece Fold Annotation:** Primary user intent answers must render within the top 350px viewport.
7. **Directional PageRank Conduits:** Equity must flow systematically (Outer Node $\rightarrow$ Hub $\rightarrow$ Core Pillar).
8. **3x Anchor Text Diversity Rule:** Exact-match target keywords must never exceed 3 occurrences sitewide.
9. **Zero-Hallucination Schema Standards:** Never output deprecated schemas (`HowTo`, `SpecialAnnouncement`, `ClaimReview`).
10. **Information Gain Differentiation:** Ensure content introduces original empirical data beyond SERP consensus.
